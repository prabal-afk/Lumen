Beat reaction

Spotify doesn't share beat data with new apps, so Lumen listens to the sound itself. The audio is analysed in your browser and never recorded or sent anywhere.

Set up Spotify

Lumen reads what you're playing through Spotify. You only do this once.

  1. Open the Spotify developer dashboard and create an app.
  2. Add this Redirect URI to it:
  3. Tick Web API, save, then copy the app's Client ID and paste it here.

Spotify requires the account that owns the app to have Premium. A new app can have up to 5 users.
